# CODECRAFT — บทที่ 1: ชนิดข้อมูลและตัวแปร (สื่อการเรียนการสอนภาษา C)

สื่อการเรียนการสอนภาษา C สำหรับนักเรียนระดับ ปวช.

**ไฟล์วิดีโอ:** `CODECRAFT-lesson1.mp4` — ความยาวประมาณ 3:26 นาที
เป็นวิดีโอ 8 ฉากพร้อมเสียงบรรยายภาษาไทย และช่วงคิดคำตอบ 5 วินาที
ระยะเวลาจริงสั้นกว่าเป้าหมาย 5:30 นาที เนื่องจากความยาวเสียงบรรยายที่สร้างไว้

นอกจากนี้ยังมีเว็บบทเรียน `index.html` สำหรับเปิดดูแบบโต้ตอบ

## วิธีเปิดใช้งาน
- เปิดไฟล์ `lesson/index.html` ในเบราว์เซอร์ (แนะนำเปิดผ่าน local server)
- หรือรัน `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/lesson/`
- กด **▶ เริ่มบทเรียน** (จำเป็นต้องกดเพื่อเปิดเสียงตามนโยบายเบราว์เซอร์)
- ควบคุมด้วยปุ่ม ▶/⏸ ย้อน ◀ ถัดไป ▶▶ เริ่มใหม่ ↺ ปิดเสียง 🔊 และจุดฉากด้านล่าง

## โครงสร้างไฟล์
```
lesson/
├── index.html          # โปรแกรมเล่นบทเรียน (player) แบบสมบูรณ์

assets/
├── audio/
│   ├── scene1.mp3 ... scene8.mp3   # เสียงบรรยายไทย 8 ฉาก
└── img/
    ├── oc-1.jpg, oc-2.jpg          # ตัวละคร OC ผู้สอน (จากไฟล์ที่ผู้ใช้แนบ)
    ├── bg-intro.jpg                # พื้นหลังเปิด/ปิดบทเรียน
    ├── bg-concept.jpg              # พื้นหลังแนวความหมายตัวแปร/ชนิดข้อมูล

    └── bg-finale.jpg               # พื้นหลังควิซ/เฉลย
```

## หมายเหตุเกี่ยวกับเสียง
- เสียงบรรยายภาษาไทยสร้างด้วยโครงข่ายเสียง (Thai voice) ที่ลงทะเบียนตามแนวทาง
  การออกเสียงจากไฟล์อ้างอิง ElevenLabs ที่ผู้ใช้ระบุ (สำเนียงไทย เป็นธรรมชาติ)
- เพื่อความสม่ำเสมอ เนื้อหาที่มีข้อความกำกับ (กล่องตัวแปร, การ์ดชนิดข้อมูล,
  โค้ด, ตัวเลือกควิซ) ถูกสร้างด้วย HTML/CSS แทนการวาดเป็นภาพ เพื่อป้องกัน
  ข้อความภาษาไทยหรือโค้ดเพี้ยนในภาพ AI

## การนำไปใช้ต่อ
- สามารถนำไฟล์ `assets/audio/scene*.mp3` ไปประกอบในโปรแกรมตัดต่อวิดีโอ (เช่น CapCut, Premiere)
  จับคู่กับภาพตามตารางด้านบน เพื่อสร้างคลิปวิดีโอขั้นสุดท้ายได้
- `lesson/index.html` สามารถนำไปฝังในเว็บ CODECRAFT ต่อได้โดยไม่พึ่งพาอินเทอร์เน็ต
