ตรวจความพร้อมห้องเรียน

สำหรับทดสอบบนคอมจริงแต่ละเครื่อง ก่อนสอน 20 เครื่อง

วิธีทดสอบ

  1. เปิดหน้านี้บนทุกเครื่อง ใส่หมายเลขเครื่อง ไม่ต้องใส่ชื่อหรืออีเมล
  2. เลือกภาษาและระบุสภาพไฟล์ตามที่ทราบ จากนั้นกดเริ่มพร้อมกันตามสัญญาณครู
  3. ตรวจผล ส่งไฟล์ผลให้ครูหรือถ่ายรูป แล้วทำซ้ำสำหรับ C และ Python

“ยังไม่เตรียม” เป็นการระบุด้วยตนเอง หน้านี้ไม่ล้างหรือพิสูจน์แคช หากต้องการวัดโหลดครั้งแรกจริง ให้ใช้เบราว์เซอร์โปรไฟล์ใหม่หรือเครื่องที่ยังไม่เคยโหลด โดยไม่ลบข้อมูลการเรียนเดิม

โค้ดทดสอบรันในเบราว์เซอร์ของแต่ละเครื่อง ไม่ส่งโค้ดหรือผลไปเก็บบนเซิร์ฟเวอร์ ขณะตรวจเน็ตจะมีคำขอเล็ก ๆ ไปยังเว็บไซต์ ผลเป็นตัวอย่าง ไม่รับประกันทุกโปรแกรมหรือการใช้งานบัญชี

สำหรับนักเรียน / เครื่องที่ทดสอบ

ยังไม่ได้ทดสอบ

เวลาแต่ละรอบรวมเวลาที่รอโหลดหรือเริ่มตัวรันในรอบนั้น ถ้าขึ้นไม่ผ่านให้บันทึกผลและแจ้งครู ปุ่มดาวน์โหลดสร้างไฟล์ JSON ในเครื่อง

สำหรับครู: รวมผลจากทุกเครื่อง

รวบรวมไฟล์ JSON ที่นักเรียนดาวน์โหลด แล้วเลือกไฟล์ทั้งหมดที่นี่ การรวมผลทำบนเครื่องครูเท่านั้น ไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์

ยังไม่มีผลรวม

เครื่องภาษาสภาพที่ระบุตรวจเว็บรอบ 1รอบ 2ผล

จำนวนผลไม่เท่ากับจำนวนเครื่องที่แตกต่างเสมอไป: เครื่องหนึ่งอาจส่งหลายภาษา/หลายรอบ ตรวจหมายเลขซ้ำและผลที่ขาดด้วยตนเอง ไม่ควรนำข้อมูลส่วนตัวใส่ในชื่อเครื่อง
