# Kuroya Window Manager — โปรแกรมจัดการหน้าวินโดว์บน Windows

ยูทิลิตี้จัดการหน้าต่างบน Windows 10/11 ในไฟล์เดียว (`window_manager.py`) ทำงานได้เลยโดย
**ไม่ต้องติดตั้งไลบรารีเพิ่ม** — ใช้แค่ไลบรารีมาตรฐานของ Python (`ctypes` เรียก Win32 API
และ `tkinter` ที่มากับตัวติดตั้ง Python จาก python.org)

## ฟีเจอร์

- **โซนสแนปหน้าต่าง (FancyZones-lite)** — 7 เลย์เอาต์: ครึ่งซ้าย–ขวา, หลัก ⅔ + เสริม ⅓,
  สามคอลัมน์, หลัก 60% + ข้างคู่, ตาราง 2×2, ตาราง 3×2, เต็มจอ
- **ลากหน้าต่างไปวางบนโซน** — จับแถบหัวข้อลากเกิน ~60px ผังโซนจะขึ้นมาเอง ปล่อยบนโซนไหน
  หน้าต่างก็เข้าโซนนั้น (มีไฮไลต์โซนที่เมาส์ชี้)
- **แถบจัดการหน้าต่างแบบลอย** ที่ขอบล่างจอ — ค้นหา / คลิกสลับ / ย่อ (–) /
  ย่อ–ขยายเต็ม (▢) / ปิด (✕) ทีละหน้าต่าง รวมถึงปุ่ม "ย่อทั้งหมด"
- **จำตำแหน่งเดิม** — ก่อนสแนปครั้งแรกจะจดตำแหน่งเดิมไว้ กด Ctrl+Alt+0 (หรือกดฮอตคีย์โซนเดิมซ้ำ) เพื่อคืน
- **ทำงานได้หลายจอ** — โซนคำนวณจากจอที่หน้าต่างอยู่ / จอที่เมาส์ชี้ (พื้นที่ทำงานไม่ทับ taskbar)
- **จำการตั้งค่า** — เลย์เอาต์, ลาก-สแนป, ระยะเว้นโซน, ตำแหน่งแถบ บันทึกใน `settings.json`

## วิธีรัน

ต้องมี Python 3.8+ ที่ติดตั้งจาก [python.org](https://www.python.org/downloads/) (ติ๊ก
"Install launcher" และ "Add to PATH" ตอนติดตั้ง) จากนั้นเลือกวิธีใดวิธีหนึ่ง:

1. **ดับเบิลคลิก `run_window_manager.bat`** — รันแบบไม่มีหน้าต่างคอนโซล (แนะนำ)
2. หรือเปิด CMD/PowerShell:
   ```bat
   pythonw window_manager.py   :: รันปกติ (ไม่มีคอนโซล)
   python window_manager.py    :: รันพร้อม log เอาไว้ดีบัก
   ```
3. แถบจัดการหน้าต่างจะลอยอยู่กลางล่างของจอ ลากย้ายได้จากแถบหัวข้อ กด `–` เพื่อย่อเหลือแท็บ
   เล็ก ๆ มุมล่างขวา คลิกขวาที่แถบเพื่อเปิดเมนูตั้งค่า

## ฮอตคีย์ทั้งหมด

| ฮอตคีย์ | ทำอะไร |
|---|---|
| `Ctrl+Alt+Z` | เปิด/ปิดผังโซนเต็มจอ — กดเลข `1`–`9` หรือคลิกโซน เพื่อสแนปหน้าต่างที่ใช้งานอยู่ |
| `Ctrl+Alt+1` … `9` | สแนปหน้าต่างที่ใช้งานเข้าโซนที่ n ของเลย์เอาต์ปัจจุบัน |
| `Ctrl+Alt+←` / `→` | สแนปครึ่งซ้าย / ครึ่งขวา |
| `Ctrl+Alt+↑` | ขยายเต็มจอ |
| `Ctrl+Alt+↓` | ย่อลง taskbar |
| `Ctrl+Alt+0` | คืนตำแหน่ง/ขนาดเดิมก่อนถูกสแนป |
| `Ctrl+Alt+L` | วนสลับเลย์เอาต์ถัดไป (มีภาพตัวอย่างเด้งขึ้นแวบหนึ่ง) |
| `Ctrl+Alt+S` | ซ่อน/แสดงแถบจัดการหน้าต่าง (ย่อเป็นแท็บ ⊞ มุมล่างขวา) |
| `Ctrl+Alt+D` | ย่อทุกหน้าต่าง |
| `Ctrl+Alt+Q` | ออกจากโปรแกรม |

## การตั้งค่า

แก้ได้จากเมนูคลิกขวาบนแถบ หรือแก้ไฟล์ `settings.json` โดยตรง:

```json
{
  "layout": "halves",     // halves | main_left | thirds | main_side | grid22 | grid23 | full
  "drag_snap": true,      // เปิด/ปิดการลากหน้าต่างไปวางบนโซน
  "gap_px": 8,            // ระยะเว้นระหว่างโซน (0/4/8/12/16)
  "panel_x": null,        // ตำแหน่งแถบ (จำอัตโนมัติเมื่อลาก)
  "panel_y": null
}
```

## แก้ปัญหา

- **ฮอตคีย์บางปุ่มไม่ทำงาน** — ปุ่มนั้นถูกแอปอื่นลงทะเบียนไว้ แถบสถานะจะเตือนเป็นสีแดงให้อัตโนมัติ
  แอปที่ชอบชนกันเช่น Discord/แปลงภาษา/โปรแกรมบันทึกหน้าจอ — ปิดฝั่งนั้นหรือแก้ปุ่มในแอปนั้น
- **ลาก-สแนปเด้งเกินโอกาส / รำคาญ** — เมนูคลิกขวา → ปิด "ลากหน้าต่างไปวางบนโซน"
  (ระบบจะจับเฉพาะการลากที่แถบหัวข้อเท่านั้นอยู่แล้ว)
- **หน้าต่างบางบานไม่ยอมสแนป** — หน้าต่างที่รันสิทธิ์ administrator (เช่น Task Manager แบบ elevated)
  หรือเกมโหมด fullscreen-exclusive Windows ไม่อนุญาตให้ควบคุมจากโปรแกรมสิทธิ์ปกติ
- **อยากเริ่มอัตโนมัติตอนเปิดเครื่อง** — กด `Win+R` พิมพ์ `shell:startup` แล้วสร้าง shortcut
  ไปที่ `run_window_manager.bat` วางไว้ในโฟลเดอร์นั้น
- **ลืมว่ารันอยู่ไหม** — รันซ้ำจะมีข้อความ "กำลังรันอยู่แล้ว" ป้องกันการเปิดซ้อน

## หมายเหตุทางเทคนิค

- โค้ดทั้งหมดอยู่ใน `window_manager.py`: Win32 API ผ่าน `ctypes` (EnumWindows,
  SetWindowPos, RegisterHotKey, GetMonitorInfo ฯลฯ), UI ด้วย `tkinter`,
  ตั้งค่า DPI awareness ให้พิกัดตรงกับจอ HiDPI
- `python window_manager.py --check` รันได้ทุกแพลตฟอร์ม (ใช้ตรวจการคำนวณโซน/เลย์เอาต์)
- โปรแกรมนี้แยกจากแอป Anime Notebook (Streamlit) ใน repo เดียวกัน — ไม่เกี่ยวกัน
