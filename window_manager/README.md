# Kuroya Window Manager — โปรแกรมจัดการหน้าวินโดว์บน Windows

ยูทิลิตี้จัดการหน้าต่างบน Windows 10/11 ในไฟล์เดียว (`window_manager.py`) ทำงานได้เลยโดย
**ไม่ต้องติดตั้งไลบรารีเพิ่ม** — ใช้แค่ไลบรารีมาตรฐานของ Python (`ctypes` เรียก Win32 API
และ `tkinter` ที่มากับตัวติดตั้ง Python จาก python.org)

## ฟีเจอร์

- **โซนสแนปหน้าต่าง (FancyZones-lite)** — 7 เลย์เอาต์: ครึ่งซ้าย–ขวา, หลัก ⅔ + เสริม ⅓,
  สามคอลัมน์, หลัก 60% + ข้างคู่, ตาราง 2×2, ตาราง 3×2, เต็มจอ
- **ลากหน้าต่างไปวางบนโซน** — จับแถบหัวข้อลากเกิน ~60px ผังโซนจะขึ้นมาเอง ปล่อยบนโซนไหน
  หน้าต่างก็เข้าโซนนั้น (มีไฮไลต์โซนที่เมาส์ชี้)
- **แถบจัดการหน้าต่างแบบลอย** ที่ขอบล่างจอ — ค้นหา / คลิกสลับ / ย่อ (–) /
  ย่อ–ขยายเต็ม (▢) / ปิด (✕) ทีละหน้าต่าง รวมถึงปุ่ม "ย่อทั้งหมด"
- **แถบเพลงลอย (Media Bar) สไตล์ Windows 11** — รูปปก + ชื่อเพลง/ศิลปิน/ช่อง,
  แถบเวลา (คลิกเพื่อเลื่อน), ปุ่ม ⏮ ⏸/▶ ⏭ — รู้เพลงที่กำลังเล่นจาก Chrome/Edge
  (YouTube), Spotify ฯลฯ ผ่าน Windows SMTC ลากย้ายได้ ซ่อน/แสดงด้วย Ctrl+Alt+M
  (ต้องติดตั้งไลบรารีเสริมก่อน — ดับเบิลคลิก `install_media_support.bat`)
- **ซิงค์กับทุกแท็บ/คลิปที่มีเสียง** — แม้เว็บไซต์ไม่รายงานชื่อเพลงให้ Windows แถบจะจับเสียงจริง
  ระดับโปรเซสด้วย WASAPI (ไม่ต้องติดตั้งเพิ่ม) แล้วแสดงการ์ด "กำลังเล่นเสียง: Chrome" พร้อม
  **มิเตอร์เสียงที่เต้นตามเสียงจริงเรียลไทม์** และปุ่ม ⏮ ▶ ⏭ ที่ส่ง media key ของ Windows
  ไปควบคุมแท็บ/แอปที่กำลังเล่น (Chrome/YouTube รับ media key อยู่แล้ว)
- **ครอบคลุมทั้งผ่านและไม่ผ่าน Chrome** — อ่าน "ทุกเซสชันสื่อ" ของ Windows พร้อมกัน
  (Chrome + Spotify + Edge เปิดค้างหลายตัวก็ได้) แล้วเลือกโชว์ **ตัวที่กำลังเล่นจริง**
  ปุ่มควบคุมยิงไปเซสชันที่เล่นอยู่เสมอ
- **แถบปรับความดังหลัก (master volume) ในโหมดเสียง** — คลิกหรือลากแถบสีขาวเพื่อปรับ
  ความดังทั้งเครื่องทันที (ไม่ต้องเปิด sound mixer)
- **ทำงานอัตโนมัติทั้งวงจร** — เปิดเครื่องรันเอง (shortcut ใน shell:startup), เปิดเพลง/มีเสียงแล้ว
  แถบโผล่เอง, เงียบไป 8 วิซ่อนเอง, จำตำแหน่งแถบที่ลากไว้
- **จำตำแหน่งเดิม** — ก่อนสแนปครั้งแรกจะจดตำแหน่งเดิมไว้ กด Ctrl+Alt+0 (หรือกดฮอตคีย์โซนเดิมซ้ำ) เพื่อคืน
- **ทำงานได้หลายจอ** — โซนคำนวณจากจอที่หน้าต่างอยู่ / จอที่เมาส์ชี้ (พื้นที่ทำงานไม่ทับ taskbar)
- **จำการตั้งค่า** — เลย์เอาต์, ลาก-สแนป, ระยะเว้นโซน, ตำแหน่งแถบ บันทึกใน `settings.json`

## วิธีรัน (ง่ายสุด: ไฟล์เดียว ดับเบิลคลิกครั้งเดียว)

**วิธีที่ 1 — ตัวติดตั้งอัตโนมัติ (แนะนำ) ไม่ต้องมี Python มาก่อนก็ได้:**

1. ดาวน์โหลดไฟล์เดียว: [`setup_kuroya.bat`](https://github.com/affranphanjampee-art/kuroya/raw/arena/d7201cd1-kuroya/window_manager/setup_kuroya.bat)
2. ดับเบิลคลิกแล้วรอ — สคริปต์จะทำเองครบ:
   - ถ้าเครื่องยังไม่มี Python → ติดตั้งให้เอง (ผ่าน winget หรือดาวน์โหลดจาก python.org)
   - ติดตั้งไลบรารีแถบเพลง (`winsdk` + `Pillow`)
   - ดาวน์โหลดโปรแกรมไปไว้ที่ `%LOCALAPPDATA%\KuroyaWM`
   - สร้างปุ่มลัดบนเดสก์ท็อป + ตั้งเปิดอัตโนมัติตอนเปิดเครื่อง
   - รันโปรแกรมขึ้นมาเลย แถบจัดการหน้าต่างจะลอยขึ้นที่กลางล่างของจอ

ถ้าดาวน์โหลดตัวโปรแกรม (โฟลเดอร์นี้) มาไว้ในเครื่องแล้ว ดับเบิลคลิก `setup_kuroya.bat`
ที่อยู่ข้าง ๆ ไฟล์ — สคริปต์จะจับได้เองว่าเป็นโหมด repo และข้ามการดาวน์โหลด

**วิธีที่ 2 — รันเอง (มี Python อยู่แล้ว):**
2. หรือเปิด CMD/PowerShell:
   ```bat
   pythonw window_manager.py   :: รันปกติ (ไม่มีคอนโซล)
   python window_manager.py    :: รันพร้อม log เอาไว้ดีบัก
   ```
3. แถบจัดการหน้าต่างจะลอยอยู่กลางล่างของจอ ลากย้ายได้จากแถบหัวข้อ กด `–` เพื่อย่อเหลือแท็บ
   เล็ก ๆ มุมล่างขวา คลิกขวาที่แถบเพื่อเปิดเมนูตั้งค่า

## ฮอตคีย์ทั้งหมด

| ฮอตคีย์ | ทำอะไร |
|---|---|
| `Ctrl+Alt+Z` | เปิด/ปิดผังโซนเต็มจอ — กดเลข `1`–`9` หรือคลิกโซน เพื่อสแนปหน้าต่างที่ใช้งานอยู่ |
| `Ctrl+Alt+1` … `9` | สแนปหน้าต่างที่ใช้งานเข้าโซนที่ n ของเลย์เอาต์ปัจจุบัน |
| `Ctrl+Alt+←` / `→` | สแนปครึ่งซ้าย / ครึ่งขวา |
| `Ctrl+Alt+↑` | ขยายเต็มจอ |
| `Ctrl+Alt+↓` | ย่อลง taskbar |
| `Ctrl+Alt+0` | คืนตำแหน่ง/ขนาดเดิมก่อนถูกสแนป |
| `Ctrl+Alt+L` | วนสลับเลย์เอาต์ถัดไป (มีภาพตัวอย่างเด้งขึ้นแวบหนึ่ง) |
| `Ctrl+Alt+S` | ซ่อน/แสดงแถบจัดการหน้าต่าง (ย่อเป็นแท็บ ⊞ มุมล่างขวา) |
| `Ctrl+Alt+M` | แสดง/ซ่อนแถบเพลงลอย (Media Bar) |
| `Ctrl+Alt+D` | ย่อทุกหน้าต่าง |
| `Ctrl+Alt+Q` | ออกจากโปรแกรม |

## การตั้งค่า

แก้ได้จากเมนูคลิกขวาบนแถบ หรือแก้ไฟล์ `settings.json` โดยตรง:

```json
{
  "layout": "halves",     // halves | main_left | thirds | main_side | grid22 | grid23 | full
  "drag_snap": true,      // เปิด/ปิดการลากหน้าต่างไปวางบนโซน
  "gap_px": 8,            // ระยะเว้นระหว่างโซน (0/4/8/12/16)
  "panel_x": null,        // ตำแหน่งแถบ (จำอัตโนมัติเมื่อลาก)
  "panel_y": null,
  "media_on": true,       // แถบเพลงลอย
  "media_x": null,        // ตำแหน่งแถบเพลง (จำอัตโนมัติเมื่อลาก)
  "media_y": null
}
```

## แก้ปัญหา

- **ดับเบิลคลิกแล้วหน้าต่างเด้งปิดไปเฉย ๆ** — รันผ่าน CMD ดูข้อความ: เปิด CMD แล้วลากไฟล์
  `setup_kuroya.bat` ลงในหน้าต่าง CMD กด Enter ข้อความ error จะค้างให้อ่าน/ก๊อปได้
- **สคริปต์ setup ติดตั้ง Python ไม่สำเร็จ** — เปิด PowerShell รัน `winget install Python.Python.3.12`
  เอง หรือติดตั้งจาก python.org (ติ๊ก "Add python.exe to PATH") แล้วรัน setup ใหม่อีกครั้ง
  (ต้องปิดหน้าต่าง CMD เดิมแล้วเปิดใหม่ เพื่อให้ PATH รีเฟรช)

- **ฮอตคีย์บางปุ่มไม่ทำงาน** — ปุ่มนั้นถูกแอปอื่นลงทะเบียนไว้ แถบสถานะจะเตือนเป็นสีแดงให้อัตโนมัติ
  แอปที่ชอบชนกันเช่น Discord/แปลงภาษา/โปรแกรมบันทึกหน้าจอ — ปิดฝั่งนั้นหรือแก้ปุ่มในแอปนั้น
- **ลาก-สแนปเด้งเกินโอกาส / รำคาญ** — เมนูคลิกขวา → ปิด "ลากหน้าต่างไปวางบนโซน"
  (ระบบจะจับเฉพาะการลากที่แถบหัวข้อเท่านั้นอยู่แล้ว)
- **หน้าต่างบางบานไม่ยอมสแนป** — หน้าต่างที่รันสิทธิ์ administrator (เช่น Task Manager แบบ elevated)
  หรือเกมโหมด fullscreen-exclusive Windows ไม่อนุญาตให้ควบคุมจากโปรแกรมสิทธิ์ปกติ
- **อยากเริ่มอัตโนมัติตอนเปิดเครื่อง** — กด `Win+R` พิมพ์ `shell:startup` แล้วสร้าง shortcut
  ไปที่ `run_window_manager.bat` วางไว้ในโฟลเดอร์นั้น
- **ลืมว่ารันอยู่ไหม** — รันซ้ำจะมีข้อความ "กำลังรันอยู่แล้ว" ป้องกันการเปิดซ้อน
- **แถบเพลงไม่ขึ้น** — ยังไม่ได้ติดตั้งไลบรารีเสริม: ดับเบิลคลิก `install_media_support.bat`
  (หรือ `pip install winsdk Pillow`) แล้วรันโปรแกรมใหม่
- **แถบเพลงขึ้นแต่ไม่แสดงเพลง** — แหล่งเพลงต้องรายงานสถานะให้ Windows (SMTC) เหมือนที่จอ
  ควบคุมมีเดียของ Windows 11 ใช้: Chrome/Edge เล่น YouTube ได้, Spotify ได้, บางแอป/เกม
  ไม่รายงานจึงแสดงไม่ได้ — แต่โปรแกรมจะสลับไปการ์ดมิเตอร์เสียงอัตโนมัติเมื่อจับได้ว่ายังมีเสียงเล่นอยู่
- **ปุ่ม ▶/⏸ กดแล้วเพลงไม่หยุด (โหมดมิเตอร์เสียง)** — โหมดนี้ส่ง media key ของ Windows ไปให้
  แอปที่รับคำสั่งสื่อตัวล่าสุดควบคุม ถ้าแท็บที่เล่นไม่รับ media key ก็จะไม่ส่งผล (ดูชื่อเพลง/เลื่อนเวลาได้
  เฉพาะแหล่งที่รายงาน SMTC เช่น YouTube บน Chrome/Edge และ Spotify)
- **รูปปกเพลงไม่แสดง** — ติดตั้ง Pillow เพิ่ม (`pip install Pillow`) ใช้แปลง/ตัดมุมโค้งรูปปก
- **แถบเพลงบังอยู่บนหน้าอื่น** — คลิกขวาที่แถบเพลง → เอาติ๊ก "อยู่บนสุดเสมอ" หรือกด Ctrl+Alt+M ซ่อน

## หมายเหตุทางเทคนิค

- โค้ดหลักอยู่ใน `window_manager.py`: Win32 API ผ่าน `ctypes` (EnumWindows,
  SetWindowPos, RegisterHotKey, GetMonitorInfo ฯลฯ), UI ด้วย `tkinter`,
  ตั้งค่า DPI awareness ให้พิกัดตรงกับจอ HiDPI
- แถบเพลงอยู่ใน `media_bar.py` (โหลดเฉพาะบน Windows): อ่านสถานะเพลงผ่าน WinRT
  GlobalSystemMediaTransportControls (แพ็กเกจ `winsdk` หรือ `winrt-*`) ทุก ~0.8 วิ —
  รวม **ทุกเซสชัน** (get_sessions) เลือกตัวที่กำลังเล่น, มุมโค้งทำด้วย `-transparentcolor`
  ของ tkinter, รูปปกตัดมุมด้วย Pillow (ถ้ามี)
- ตัวจับเสียงจริง/ความดังหลักใช้ COM ผ่าน ctypes ล้วน: IMMDeviceEnumerator →
  IAudioSessionManager2 → IAudioSessionEnumerator → IAudioMeterInformation
  (มิเตอร์ต่อเซสชัน) และ IAudioEndpointVolume (ปรับ master volume) — ไม่ต้อง pip เพิ่ม
- `python window_manager.py --check` รันได้ทุกแพลตฟอร์ม (ใช้ตรวจการคำนวณโซน/เลย์เอาต์)
- โปรแกรมนี้แยกจากแอป Anime Notebook (Streamlit) ใน repo เดียวกัน — ไม่เกี่ยวกัน
